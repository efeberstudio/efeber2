# EFEBER2 — Frequently Asked Questions

### What is EFEBER2?
A Windows modding studio focused on creating **Garry's Mod Glide vehicle addons** from supported GTA assets and converting compatible **Simfphys → Glide** vehicles.

### What is Glide?
Glide is a Garry's Mod vehicle system. EFEBER2 creates vehicle files and configurations intended for use with it.

### Can I turn any GTA vehicle into a Glide car?
Not necessarily. Compatibility depends on the original model, texture layout, wheel structure, and compilation requirements.

### What source games does EFEBER2 support?
Its vehicle workflow targets GTA San Andreas and supported GTA V Legacy asset formats. Other formats are not guaranteed.

### How does the Simfphys → Glide converter work?
Paste a supported Steam Workshop link and start conversion; check the resulting addon in-game.

### Is it fully automatic?
It aims to automate repetitive steps, but special wheels, suspension, attachments, textures, and seats can still require fixes.

### Are driver and passenger seats automatically positioned?
The application attempts automatic positioning using source data and fallback estimates. Check them in the preview and inside GMod.

### Can I choose vehicle engine and horn sounds?
Yes, in the vehicle settings. The in-app preview volume setting does not determine how loud the vehicle is in GMod.

### What does the Sports Car driving preset do?
It changes supported engine, transmission, steering, braking, mass and suspension values. Real handling depends on the vehicle.

### Can GMod's color tool recolor the car?
If its body materials have been configured as paintable and the output supports it, yes.

### Do I need Garry's Mod and Glide installed?
Yes, to actually drive and test exported Glide vehicles.

### Can every character become an animated player model?
No. Character rigs, weights, materials, and bones may need manual work.

### Does EFEBER2 export for CS2?
No. That target was removed from the current beta.

### Is there an AI paint generator?
No. The AI demo was removed.

### Is EFEBER2 open-source?
Not currently. The GitHub repository hosts documentation and public beta downloads.

### Is EFEBER2 an official Glide or Facepunch application?
No. It is an independently developed community project.

### How can I report a bug or suggest a feature?
Open a [GitHub issue](https://github.com/efeberstudio/efeber2/issues) with your EFEBER2 version, mod source link, reproduction steps, expected behavior, actual behavior, and images/logs.
