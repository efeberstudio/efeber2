# Getting started with EFEBER2 and Glide

## Requirements
- Windows 10/11 64-bit
- Garry's Mod
- **Glide addon** installed to use the generated Glide vehicles in-game
- Access to your source vehicle assets or Workshop item

## Download
1. Visit [GitHub Releases](https://github.com/efeberstudio/efeber2/releases).
2. Download the beta Windows `.exe` file from **Assets**.
3. Run EFEBER2. If Windows warns that the app is not signed, verify that the file came from this project's official Releases page.
4. Confirm your Garry's Mod / output directory when prompted.

## Option 1: GTA vehicle → Glide
1. Open **Glide Vehicle Studio**.
2. Import a supported GTA SA DFF/TXD or GTA V Legacy vehicle.
3. Inspect the 3D vehicle, scale, wheels, and seat positions.
4. Select materials and configure the paintable car body.
5. Under the vehicle settings, choose a name, engine sound, horn, and driving preset.
6. Export. Test collision, wheel direction, seats, and handling in GMod.

## Option 2: Simfphys → Glide
1. Copy the **Steam Workshop** URL of a supported Simfphys vehicle.
2. Paste it in the **Simfphys → Glide** section.
3. Start the conversion and wait for the output.
4. Remove any older generated copy before installing the new addon.
5. Spawn the vehicle in GMod with Glide and verify wheels, suspension, and driver seat.

## Option 3: GMod Player Model
Use the separate Player Model tools for supported character assets. Check UVs, rigging, bones and animations. **CS2 target support is not available in the current beta.**

## Known beta limitations
- Custom Simfphys wheel and seat configurations may not convert correctly.
- GTA source model materials and collision bodies may need manual corrections.
- Model formats, attachments, and dependencies vary.
